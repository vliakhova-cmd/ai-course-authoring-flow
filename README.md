# AI Course Authoring

A prototype flow for AI-assisted course authoring, built from Figma designs: a Content Library browser, an AI-driven course generation flow (compose → thinking → result → saving), a generated course viewer built from a sample clinical-study PDF, and Course Management / Activity Preview pages with SCORM-style progress tracking.

Live: https://vliakhova-cmd.github.io/ai-course-authoring-flow/

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploys automatically to GitHub Pages via `.github/workflows/deploy.yml` on every push to `main`.
